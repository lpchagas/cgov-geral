## Modelo 1 — PGD (Palestra em auditório, 60 min)

**Arquivo:** `apresentacoes/arq_aula02_pressupostos-PGD_v2.0.pdf`
**Aula:** Gestão para Resultados no ICMBio — Bloco Teórico I
**Docente:** [Docente responsável]

**Estrutura:**
- Cabeçalho com tabela de metadados (Docente, Data, Horário, Formato, Público,
  Slides estimados)
- Mensagem central em destaque
- Estrutura narrativa resumida (linha única com blocos e tempos)
- Roteiro de abertura sugerido (90 segundos, subdividido por elemento)
- Tabela de slides organizada em BLOCOS (não seções)
  - 6 blocos + 3 atividades Mentimeter
  - 23 slides + 3 Mentimeter
  - Colunas: Nº | Título assertivo | Mensagem principal | Conteúdo visual |
    Notas do apresentador | Tempo
- Proposta de atividades Mentimeter (tabela separada)
- Perguntas de interação sem Mentimeter (por bloco)
- Plano de contingência — trechos suprimíveis (lista ordenada por prioridade)
- Orientações de produção dos slides

**Características marcantes:**
- Títulos de slides em formato assertivo com travessão
- Notas do apresentador com falas completas, pausas e transições
- Slides marcados como suprimíveis quando o tempo apertar
- Atividades Mentimeter com objetivo pedagógico explícito
- Exemplos hipotéticos marcados como [EXEMPLO HIPOTÉTICO]

## Modelo 2 — Governança Multinível (Palestra + Rodas de Conversa, 180 min)

**Arquivo:** `apresentacoes/2026-07-14_FGBio2026_Governanca-Multinivel_Arquitetura-Apresentacao_v1.0.md`
**Aula:** Governança Multinível na Gestão Ambiental Pública
**Docente:** [Docente responsável] (também como moderador das rodas)

**Estrutura:**
- Cabeçalho com referência ao plano de aula base e versão
- Arquitetura narrativa — visão geral com tabela de seções
- Mensagem central em bloco de citação
- Tabela de slides organizada em SEÇÕES (não blocos)
  - 8 seções cobrindo palestra, Mentimeter, interação, rodas, debate
  - 25 slides totais
  - Colunas idênticas ao Modelo 1
- Notas adicionais de tempo dentro de cada seção
- Especificação detalhada do slide de mapa de governança (após a tabela)
- Roteiro de moderação para as rodas de conversa (seções 4 e 6)

**Características marcantes:**
- Cobre múltiplos formatos na mesma apresentação (palestra + roda + debate)
- Slides de transição entre modalidades
- Slides para Mentimeter integrados na tabela principal (não separados)
- Notas de tempo dentro das seções para gestão de atraso
- Slide de "caso hipotético" como âncora narrativa do início ao fim
- Conteúdo visual especificado em detalhe para o slide de mapa principal

## Diferenças entre os dois modelos e quando usar cada um

| Característica | Modelo PGD | Modelo Governança |
|---------------|------------|-------------------|
| Formato | Palestra pura | Palestra + Rodas + Debate |
| Duração | 60 min | 180 min |
| Organização | BLOCOS | SEÇÕES |
| Mentimeter | Tabela separada | Integrado na tabela de slides |
| Complexidade | Um docente, um formato | Um docente, múltiplos formatos |
| Quando usar | Aulas de palestra simples | Aulas com múltiplos momentos |

Para aulas com formato misto (palestra + roda + debate), use o Modelo Governança.
Para palestras em auditório, use o Modelo PGD.
